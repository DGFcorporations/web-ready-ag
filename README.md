# web-ready-ag

This repository is a full-stack web application template designed to make websites ready for Artificial Intelligence Optimization (AIO) and Answer Engine Optimization (AEO). It solves the problem of AI discoverability by structuring web content so that AI-driven search engines, agents, and scrapers can easily read, parse, and interact with the site.

## Tech Stack
- **Languages:** TypeScript, Node.js
- **Frontend:** React, Vite, Tailwind CSS (with shadcn/ui components)
- **Backend:** Hono, tRPC, Drizzle ORM
- **Database Driver:** MySQL2

## How to Run

1. Install the dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build and run for production:
   ```bash
   npm run build
   npm run start
   ```

## Key Features
- **AI-Optimized:** Built-in strategies to prepare your site for AI-driven searches and intelligent agents.
- **End-to-End Type Safety:** Full-stack typing provided by TypeScript and tRPC.
- **Modern UI/UX:** Includes over 40 accessible UI components (via Radix UI and shadcn) and animated interactions.
- **Database Integrated:** Ready to go with Drizzle ORM for schema management and migrations.
- **Developer Experience:** Fully configured with Vite, ESLint, Prettier, and Vitest for seamless development and testing.
